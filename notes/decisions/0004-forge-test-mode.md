# 0004 — Forge Test Mode lists fixed example links

**Status:** accepted (owner-directed 2026-10-05).

## Context
The owner wants a small, always-there set of ready examples without generating a puzzle every time.

## Decision
- `PuzzleForge/index.html` has a Test Mode section with fixed example links.
- A puzzle appears only when it has a playable page and a link confirmed to load and solve.
- Currently listed: Pictogram, Hashi, Akari; each now has a real example link.

## Consequences
- The owner pastes the three real links once; Test Mode must never imply a logic-only puzzle is playable.
