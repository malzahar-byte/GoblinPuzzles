Skyscrapers

How to play
  • Fill every cell with a tower height 1–N so each row and column holds 1..N exactly once.
  • A clue outside an edge says how many towers are visible from that side.
  • Click cycles empty → 1 → … → N → empty; right-click clears it. Given cells are fixed.
  • Zoom with the wheel or +/−; undo/redo with Ctrl+Z / Ctrl+Y.
